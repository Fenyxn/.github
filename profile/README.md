## Featured Projects

### 🧪 Laboratory Management System (LIMS)
> A production-grade multi-tenant platform for diagnostic laboratories — deployed on GCP.

- Multi-lab tenant architecture with isolated PostgreSQL schemas per lab
- Patient registration, test management, and report generation
- Billing, invoicing, and payment tracking
- Automated WhatsApp notifications for patients
- Daily automated database backups with email delivery
- Role-based access control via Keycloak — Lab Owner, Technician, Receptionist

**Stack:** `FastAPI` `PostgreSQL` `Next.js` `TypeScript` `Keycloak` `Docker` `GCP`
