## Projects

### 🧪 Laboratory Management System
A full-stack multi-tenant platform for managing diagnostic laboratories.

**Features:**
- Multi-lab tenant architecture with isolated data per lab
- Patient registration, test management, and report generation
- Billing, invoicing, and payment tracking
- WhatsApp notifications and automated daily database backups
- Role-based access: Lab Owner, Technician, Receptionist

**Tech Stack:** FastAPI · PostgreSQL · Next.js · Keycloak · Docker
